Resources

C++ Programming

  • Tour of C++ 3rd Edition by Bjarne Stroustrup — A comprehensive introduction to C++.
  • Effective C++ 3rd Edition by Scott Meyers — An intermediate book that explains how to write idiomatic, clean code.
  • Optimizing Software in C++ by Agner Fog — A strong top-to-bottom overview about understanding and writing performant C++.

Performance Engineering

  • Algorithms for Modern Hardware by Sergey Slotin — Not quite as deep as other books, but gives a solid lay of the land/refresher of performance engineering. The case studies in chapters 11 and 12 are most interesting.
  • Matt Godbolt Skylake Talk — An overview of the CPU microarchitecture of Skylake (for more details though go to chapter 3 of ↓).
  • Performance Analysis and Tuning on Modern CPUs by Denis Bakhvalov — My favorite CS book. It goes in depth into cpu microarchitecture, understanding the wide array of performance metrics, and solidifies the cycle of gather performance metrics → match to current code behavior → create strategy to relieve bottleneck. Bakhvalov also has a website and a course in measuring performance called perf-ninja.

GPU

  • Programming Massively Parallel Processors by Wen-mei W. Hwu, David B. Kirk, Izzat El Hajj — A good first GPU book. Very helpful if you didn't have the fortune of taking a GPU class in college.
  • GPU Mode Lectures — A lecture series about various topics in GPUs. Earlier lectures especially give good background (e.g. scan algorithm, flash attention, CuTe, etc) and more recent lectures give insight into the frontier of the field. GPU Mode is also a discord with smart people doing interesting things.
